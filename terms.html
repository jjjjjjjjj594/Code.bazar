1. CodeBazaar kya hai

CodeBazaar ek marketplace hai jahan developers apna code (scripts, templates, UI clones, automations) list kar sakte hain aur buyers use kharid sakte hain. Yeh site khud koi code nahi banati na maintain karti hai (jab tak explicitly na likha ho) — har listing us seller ki responsibility hai jisne use banaya hai.

2. Purchase Process

Abhi checkout manual hai: buyer UPI se payment karta hai aur WhatsApp par payment screenshot bhejta hai. Payment verify hone ke baad seller manually buyer ko code file bhejta hai. Yeh automatic nahi hai — delivery me thoda time lag sakta hai.

3. Refunds

Chunki yeh digital products hain jo delivery ke baad turant use ho sakte hain, general policy yeh hai ki delivery ke baad refund nahi diya jaata, siwaye in cases ke:

  • Product jo describe kiya gaya tha usse kaafi alag nikla
  • File corrupt ya incomplete thi aur seller usse fix nahi kar paya

Refund request ke liye WhatsApp par order details ke saath contact karein.

4. License & Usage

Jab tak kisi specific listing me alag se na likha ho, kharida gaya code aap apne personal ya client projects me use kar sakte hain. Aap code ko resell ya redistribute (jaise-ka-taisa, ek alag product banakar) nahi kar sakte.

5. No Warranty

Sabhi code "as-is" (jaisa hai waisa) becha jaata hai — koi guarantee nahi ki woh aapke specific use-case, environment, ya requirements ke liye bug-free ya suitable hoga. Kharidne se pehle listing ka description, features, aur requirements dhyan se padh lein.

6. Contact

Kisi bhi sawaal ke liye WhatsApp ke through contact karein — link site ke header aur chat widget me diya gaya hai.
